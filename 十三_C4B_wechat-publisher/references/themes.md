# 主题色板与适用场景

> 主题系统只有 **5 个语义色槽位**，换主题 = 换 5 个颜色。
> 这样设计是为了避免"每加一个主题就复制 60 行 CSS"——
> 那样改一处样式要同步 N 份，必然漂移。

## 语义槽位

| 槽位 | 作用 | 落在哪 |
|---|---|---|
| `ink` | 正文与标题的颜色 | h2/h3/p/li/td/blockquote |
| `accent` | 强调色（标题左竖线、加粗、链接、表头底色、语言标注） | h2 边框 / strong / a / th |
| `soft` | 分隔线、表格边框 | hr / td 边框 / 页脚 |
| `code_bg` / `code_fg` | 代码块与行内代码的底/前景 | code_block / code_inline |
| `quote_bg` | 引用块与隔行表格的底色 | blockquote / summary / td_alt |

## 三套主题

| 主题 | ink | accent | 适用 | 不适合 |
|---|---|---|---|---|
| `tech-blue` | `#1f2328` | `#2563eb` | 教程、代码、技术分析 | 情感类文章（蓝色偏冷） |
| `warm` | `#3f2f1e` | `#d97706` | 学习心得、复盘、叙事 | 严谨的技术对比（橙色偏软） |
| `ink` | `#111111` | `#111111` | 随笔、评论、观点 | 代码多的文章（无强调色，代码块淹没） |

## 怎么加一个新主题

```python
THEMES["forest"] = _theme("#122117", "#15803d", "#cfe3d4",
                          "#f0fdf4", "#14532d", "#f0fdf4", "森林绿")
```

5 个颜色的取值建议：

- `ink` 与背景对比度 ≥ 7:1（公众号阅读以手机为主，对比度别省）
- `accent` 饱和度中等——太艳会抢走正文注意力
- `code_bg` 与 `quote_bg` 要足够浅，否则长代码块阅读疲劳
